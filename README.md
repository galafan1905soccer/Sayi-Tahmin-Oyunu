# Gizli Sayıyı Bul  Python ile geliştirdiğim ilk sayı tahmin oyunu. 

## Oyun kuralları - Bilgisayar 1 ile 100 arasında bir sayı seçer. - Oyuncunun 7 tahmin hakkı vardır. - Her yanlış tahminde büyük/küçük ipucu verilir. - Geçersiz girişler tahmin hakkını azaltmaz. 

## Çalıştırma Terminalde `python main.py` komutunu çalıştırın. 

## Öğrendiklerim Değişkenler, koşullar, döngüler ve kullanıcıdan veri alma.
